- [x] 2.5 Wire cancellation: Escape or blur without confirming reverts the control to the static position button without navigating. Verified with Playwright: both Escape and blur (clicking elsewhere) restore the static "N / total" display without navigating.
- [x] 2.6 Verify keyboard shortcuts (arrow keys, Cmd/Ctrl+Enter, Cmd/Ctrl+Shift+Enter) and the native-text-editing-shortcut exclusions still work unchanged now that `prevZone`/`nextZone` point at header elements.
